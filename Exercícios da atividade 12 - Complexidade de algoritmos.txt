Exercícios sobre complexidade de algoritmos - livro 2 - páginas 18 e 19

Exercício 1
Letra A

A eficiência de tempo de um algoritmo é determinada pelo número de passos necessários para resolver um dado problema. É importante notar que essa característica é obtida somente com a comparação entre diferentes algoritmos, não existindo um modelo ideal de algoritmo.


Letra B

As grandezas físicas que influenciam a eficiência de tempo são a capacidade de hardware do computador (seja o processador, disco ou memória) e da eficácia da linguagem de programação e do sistema operacional em relação ao problema analisado.


Letra C

Das grandezas citadas na letra anterior, duas são utilizadas para expressar a eficiência de tempo de um algoritmo no modelo de computação: memória e capacidade de processamento. Quanto menor a memória utilizada pelo algoritmo e/ou quanto mais instruções são executadas por unidade de tempo, melhor sua eficácia.


Letra D

As grandezas que são abstraídas são hardware de computador (não é utilizado nenhum modelo em particular) e viabilidade/eficiência (não é dada preferência a nenhuma linguagem ou sistema operacional). Essa abstração ocorre, pois, para a análise de complexidade de um algoritmo, não é interessante saber o tempo de execução particular de cada computador, mas uma comparação relativa entre os algoritmos. Para isso, abstrai-se as grandezas supracitadas e considerada-se que toda operação toma uma unidade de tempo e são executadas sequencialmente.	


Letra E

A notaçao utilizada para expressar a complexidade de tempo de um algoritmo é a Big O, pois ela verifica o máximo de recursos que um algoritmo irá utilizar e tenta reduzir, quando possível, esse uso.


Exercício 2

A notação Big O verifica o máximo de recursos que um algoritmo poderá utilizar, sem a rigidez da Small O, e tenta melhorar sua eficiência (reduzindo o uso de recursos). A função T (n), na qual "n" é o tamanho do input do algoritmo, é relacionada com a notação Big O da seguitne forma: T (n) = O (n). Como o tempo está relacionado a "n", o algoritmo possui uma complexidade linear de tempo. 

As cinco principais representações de complexidade (constante, linear, logarítmica, cúbica e qudrática) são relaçãoes entre "T" e "n" em um algoritmo, ou seja, entre um ou mais aspectos da entrada com o tempo de execução do algoritmo.

A notação Big O também pode ser utilizada para calcular quanto de espaço é consumido pelo algoritmo.

para i de 1 até n faça:

1ª parte: A complexidade é O (n), pois há um único laço de repetição.

para i de 1 até n - 2 faça:
  para j de 1 até 2*n faça:
    se i for ímpar então
      para k de 1 até n^2 faça:
        x(k) <- x(i) * x(j);
      fim para
     senão
      para k de 1 até n faça:
        x(k) <- j;
      fim para
      x(j) <- 1;
      x(i) <-$ j;
    fim se
  fim para
fim para

2ª parte: A complexidade é O (n^4), pois há três laços aninhados, sendo que o pior caso (quando "i" é ímpar) o laço mais interior possui complexidade O (n^2) por ser executado n^2 vezes. O resultado do produto entre as complexidades é O (n^4).


Exercício 4

#include <iostream>
#include <vector>
using namespace std;

int buscaLinear(vector<int>& vetor, int inicio, int fim, int v) {
    int i = 0;
    
    for (int i = inicio; i <= fim; i++) {
        if (vetor[i] == v) {
            return i; 
        }
    }
    
    return -1;
}

int main() {
    vector<int> teste = {10, 20, 30, 40, 50};
    int inicio = 0, fim = 4, numero = 0; 

    cin >> numero;

    cout << buscaLinear(teste, inicio, fim, numero) << endl; 

    return 0;
}

Complexidade do melhor caso: É O (1) e ocorre quando o elemento procurado está na primeira posição, pois o algoritmo executa apenas uma comparação (o "if") e já retorna o índice. É um número fixo de operações.

Complexidade do pior caso: É O (n) e ocorre quando o elemento procurado é o último elemento ou não existe no vetor. Tal caso obriga o algoritmo a executar o laço de repetiçao N vezes, sendo que em cada uma delas é feita uma comparação.
